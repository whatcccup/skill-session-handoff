# 安装访谈

供安装 Agent 执行。目标是让用户完成会话交接、neat-freak 和全局读取规则的安装与核验，不是立即收尾当前项目。

## 先检查，再询问

读取当前环境的安装规则，确定工具与操作系统、可用技能目录、全局规则入口、已安装版本和用户改动。只检查相关路径，不扫描其他项目或私人资料。

能从环境可靠确认的信息不重复问；无法确认的集中询问，优先使用可用的弹窗或表单，缺少工具时用对话。每轮最多三个问题：

1. **使用工具与范围**：你使用哪个 Agent？希望所有项目可用，还是仅当前项目？全局技能安装和全局规则修改分别确认，不将项目安装范围自动扩大。
2. **安装位置与已有定制**：确认工具实际支持的位置。两个技能若已存在，展示版本与差异，选择保留现有版、更新或暂缓；未知定制不得覆盖，不安装其他套装技能。
3. **全局读取规则**：展示 README 中的规则片段与拟修改文件，确认合并还是仅提供文本。已有等价规则时保持不动。工具不支持全局规则时说明限制，并询问是否只提供项目级替代方案，不假称全局生效。

## 展示安装计划并执行

列出两个技能的来源、版本/ref（能取得则记录具体 commit）、安装目标、拟改文件及现有版本处置方式。确认具体计划后执行；用户已有针对同一计划的明确授权时不重复请求。

来源：

- 会话交接：`https://github.com/whatcccup/skill-session-handoff`。
- neat-freak：`https://github.com/KKKKhazix/khazix-skills/tree/main/neat-freak`。

使用当前环境认可的安装方式。按完整目录安装，保留依赖所需的 references、scripts 等文件，neat-freak 不复制进会话交接仓库。更新前保护已有定制；冲突时停止对应项，不强制覆盖。不为安装修改模型、建立项目 Git、提交、推送或执行清理。

将全局读取片段合并到已确认的规则入口，不覆盖整份文件；去重并保留其他偏好。不把技能执行细则写入全局规则。

## 安装验收

- 实际读取两个技能的 SKILL.md，检查它们引用的资源存在，确认会话交接能按技能发现机制定位 neat-freak，而不是依赖作者电脑路径。
- 回读全局规则的目标文件，确认片段保存且无重复。文件写入成功与宿主已加载是两个状态；若需要重载，按工具实际支持的方式提示用户，不编造重载命令。
- 请用户在新会话的测试项目中验证：先询问读取了哪些规则与交接，再手动请求交接。没有交接文件时如实报告缺失；仅在用户授权的测试目录验证写入，不用真实业务文件制造过程稿或删除测试。
- 验收区分“文件已安装”“宿主已发现”“全局规则已保存”“新会话读取已验证”，未验证的明确标记。不要把目录存在当成整个流程已经成功。

## 交付给用户

简短报告安装位置、实际版本、全局规则文件、完成与待验证项，并给出一次调用示例。安装访谈只在首次安装、迁移或用户要求重配时执行，不在每次交接时重复。
