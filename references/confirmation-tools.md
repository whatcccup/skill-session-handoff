# 收尾删除的弹窗工具选择

仅在收尾有过程文件需要用户选择时读取。本文件维护工具适配；清单范围和三个选项以[交接模块](handoff.md#过程文件的完整清单及选择)为准。

## 先检查当前实际工具

查看本会话已提供的工具名称、用途、参数及模式限制；若宿主支持工具发现，再搜索其可用工具。技能不能新增工具或放宽权限。一个工具不可用或禁止批准请求，不意味着所有弹窗不可用。

| 环境 | 首选工具及条件 |
|---|---|
| Codex中已暴露异步问答工具 | `functions.request_user_input_async`（有些宿主显示为`request_user_input_async`）。仅在当前说明允许approval/批准请求时用于删除确认；本会话已验证这种工具可以显示选择弹窗 |
| Codex仅有同步问答工具 | 检查`request_user_input`的当前说明。若仅限Plan模式或明确禁止permission/approval，不能用来确认删除；继续检查其他允许的交互工具，不为了绕过限制自行切换模式 |
| Claude Code交互会话 | `AskUserQuestion`，用于展示清理范围并收集用户选择；须核对当前工具说明允许该用途。它不替代Bash等工具自身的执行权限检查 |
| Claude Agent SDK、自建Agent | 只有应用已将交互问答/批准请求接到用户可见UI，并能返回真实用户选择时使用该工具；SDK回调或MCP工具的存在本身不证明有弹窗。自动批准回调不算用户选择 |
| Claude网页/Cowork、WB、豆包、Kimi及其他Agent | 检查当前暴露的用户问答、确认表单或交互卡片工具；按真实schema调用，不套用Codex或Claude Code工具名，不假定同品牌所有产品提供相同工具 |

## 弹窗内容与返回结果

弹窗说明对象、用途、数量、建议、排除项和不可恢复风险。清单很长时，先提供可打开的完整编号清单，弹窗引用该清单的明确版本/路径及编号范围；清单之后有变化必须重新核对授权范围。

Codex异步工具示意（按当前schema替换清单内容，不原样执行示例）：

```json
{
  "questions": [{
    "title": "本次过程文件清单：1…、2…；排除正式交付；删除后无法恢复。请选择处理范围。",
    "options": ["全部保留", "仅删除建议可删项（明确编号）", "删除全部列出的过程文件（明确编号）"]
  }]
}
```

Claude Code使用`AskUserQuestion`当前提供的questions/question/header/options参数，选项label与description分别写选择和具体影响；三个选项为互斥单选。缺少该工具时不要伪造调用。

- 异步工具返回accepted仅表示问题已发出，必须等待对应问题的用户回复，不能把accepted当删除许可。
- 同步工具须返回用户实际选择；空结果、取消、预选、超时自动继续均不算主动批准。Claude Code存在可配置的问答超时，不能依据超时提交的默认结果执行删除。
- 选择全部保留即结束本次清理，不能反复弹窗催删；选择删除后，仅处理该清单获准部分。
- 不用shell执行提权、ExitPlanMode或其他不匹配用途的工具替代文件选择弹窗，不自行点击自己的批准按钮。

## 找不到可用工具时

报告检查过的工具及具体原因：未暴露、模式不符、禁止批准用途、调用失败或无法呈现UI。只有实际调用失败才能称为工具报错；未调用不能称弹窗失败。保留文件并标记清理待确认，不把“文档交接完成”写成“全部收尾完成”。后续收到明确的新用户指令时按指令层级处理，不将既往未显示的弹窗补记为已显示。

## 核对依据

- Codex异步工具：当前会话实际工具定义及已收到的交互回复，非所有Codex客户端的通用承诺。
- [Claude Code工具参考：AskUserQuestion](https://code.claude.com/docs/en/tools-reference#askuserquestion-tool-behavior)，2026-10-29核对；支持多选项交互，具体权限与可用性以当前宿主为准。
