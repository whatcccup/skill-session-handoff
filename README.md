# 会话管理

按当前意图使用三个模块：初始化、文件夹管理、会话交接与收尾。技能标识为 `session-management`，公开版本不包含旧兼容入口。

| 说法 | 行为 |
|---|---|
| 初始化项目、生成AGENTS.md | 使用原生/init或内置中文初始化流程 |
| 整理文件夹、检查命名、按上级规范归位 | 读取适用规范，具体改名清单经确认后执行 |
| 写交接、结束会话、更新HANDOFF | 核对现状、确认过程文件清理、更新当前交接 |
| 继续上次工作 | 读取规则和当前交接，不重新初始化 |

意图不明先询问；明确的多个任务按需组合。历史只在追溯时读取。tmp、预览、截图和草稿均进入过程文件清单，由用户选择保留、删除建议项或全部列明项。

## 安装与使用

将完整目录安装或导入支持Agent Skills的客户端。不能导入技能时提供SKILL.md，再按需提供对应references；只有聊天能力时输出待应用文稿，不声称已修改文件。见[平台与通用使用方式](references/platforms.md)。

交接依赖neat-freak，先复用已有安装，缺失时按[依赖说明](references/installation.md)处理。只读当前任务需要的参考文档。
